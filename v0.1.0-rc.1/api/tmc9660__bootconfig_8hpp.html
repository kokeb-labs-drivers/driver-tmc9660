Detailed Description

The bootloader's configuration memory (64 bytes, datasheet "Bootloader Configuration") as a typed BootConfig, and the external-memory partition table builder.

The configuration memory is 16 little-endian 32-bit words. Every documented field is a row of kBootFields (byte offset, shift and width as the datasheet prints them), so a field is reached by name, range checked, and the table is the single source of the layout. A field the documents leave unclear (the SPI-encoder chip-select polarity, ambiguity A16) is reachable through the raw SetWord().
