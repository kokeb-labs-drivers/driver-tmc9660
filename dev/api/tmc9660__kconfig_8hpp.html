Detailed Description

Optional ESP-IDF layer: a Config built from the CONFIG_TMC9660_* Kconfig options.

Copyright
Copyright (c) 2026 The driver-tmc9660 authors. SPDX-License-Identifier: MIT

Include this header only where you want menuconfig to choose the defaults; the driver never includes it and no driver signature depends on it. Under ESP-IDF the values come from sdkconfig.h. Without Kconfig every option falls back to the Config{} default, so KconfigDefaults() equals Config{}.

Kconfig writes a bool option set to "n" as an absent macro, so an absent option means off.

One configuration per program: the inline function below depends on the CONFIG_ macros, so every translation unit of one program must see the same values (handbook KB-CPP20-018).
