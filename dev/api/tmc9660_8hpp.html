Detailed Description

TMC9660 driver: the one header to include.

Copyright
Copyright (c) 2026 The driver-tmc9660 authors. SPDX-License-Identifier: MIT

tmc9660::TMC9660<Port> drives one TMC9660 servo controller and gate driver through a platform port you write (see tmc9660_spi_interface.hpp and tmc9660_uart_interface.hpp). The driver has no platform code, allocates nothing, throws nothing, takes no lock and is not thread-safe: give each object one owner, or guard it with one mutex.
