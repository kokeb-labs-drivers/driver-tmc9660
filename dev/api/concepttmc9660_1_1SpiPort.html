Detailed Description

Satisfied by a class that derives from SpiInterface<Port> and implements the required hooks with exactly the types above, noexcept and returning bool.

Each hook's address is matched with detail::ExactHook, which takes a member function of exactly the signature and converts no value: a hook declared with a narrower length (uint16_t len) or without noexcept does not satisfy the concept, instead of truncating every transfer silently (KB-CPP20-006).
