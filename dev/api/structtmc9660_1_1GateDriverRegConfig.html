◆ gdrv_ocp_uvw

uint32_t tmc9660::GateDriverRegConfig::gdrv_ocp_uvw {0}

MCC_GDRV_OCP_UVW, written before the start. 0 is the reset value: the lowest threshold, no blanking, no deglitch. Set the board's values: with every protection on, 0 can trip at once (GateDriverStart() then returns DeviceFault and leaves the stage off).
